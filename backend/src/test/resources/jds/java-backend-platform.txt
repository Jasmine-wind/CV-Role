Java 后端工程师｜平台交易方向

- 3 年以上 Java 后端开发经验，熟悉 Spring Boot、MySQL、Redis、Kafka。
- 理解分布式系统、缓存一致性、消息可靠性和服务治理。

- 能阅读技术文档并清晰表达设计取舍，具备良好的问题定位能力。
