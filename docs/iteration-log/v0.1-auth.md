## 4. 遇到的问题
- 浏览器前端请求后端时触发 CORS，Postman 正常但网页登录失败。
- 前端 API 层和 Pinia store 都需要 token，如果互相直接引用会产生循环依赖风险。
- Axios 响应拦截器直接返回业务 data 时，与 Axios 默认 TypeScript 类型不一致。
- 当前环境运行 `./mvnw test` 时 Mockito / Byte Buddy 无法自附加 JVM agent。

## 5. 解决方式
- 在 `SecurityConfig` 中增加 `CorsConfigurationSource`，仅允许本地前端开发端口访问 `/api/**`。
- 新增 `web/src/utils/auth-token.ts`，将 token 读写抽离为独立工具，避免 `api/request.ts` 与 `stores/auth.ts` 循环依赖。
- 将 Axios 成功响应拆包放到自定义 `request.get/post/put/delete` 方法中，拦截器只处理请求头和 401 错误。
- 使用 `./mvnw -DskipTests package` 验证后端编译和打包；Mockito 测试环境问题后续单独处理。
