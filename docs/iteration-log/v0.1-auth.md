# v0.1 用户认证

## 1. 本轮目标
按小闭环逐步推进用户认证能力，完成后端认证主链路：注册、登录、JWT 鉴权、当前用户接口。

## 2. 本轮完成内容
- 完成后端技术基线确认
- 完成 `users` 表初始化脚本
- 完成 `User` 实体
- 完成 `UserMapper`
- 完成注册 / 登录请求 DTO
- 完成登录返回 VO
- 完成统一返回结构 `Result`
- 完成业务异常 `BusinessException`
- 完成全局异常处理 `GlobalExceptionHandler`
- 完成注册服务接口与实现
- 完成登录服务接口与实现
- 完成 `POST /api/auth/register`
- 完成 `POST /api/auth/login`
- 完成用户名唯一校验
- 完成邮箱唯一校验
- 完成密码 BCrypt 加密存储
- 完成 JWT 生成器
- 完成 JWT 过滤器
- 完成 Spring Security 无状态配置
- 完成未登录访问受保护资源时的 401 JSON 返回
- 完成 `GET /api/users/me`
- 完成当前登录用户信息返回且不暴露密码哈希

## 3. 关键技术点
- Spring Boot
- Spring Security
- MyBatis-Plus
- Hibernate Validator
- BCryptPasswordEncoder
- JJWT
- PostgreSQL
- 全局异常处理
- JWT 无状态鉴权
- SecurityContext 用户信息传递
