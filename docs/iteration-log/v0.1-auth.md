# v0.1 用户认证

## 1. 本轮目标
按小闭环逐步推进用户认证能力，先完成后端基础准备、注册接口，再继续登录与 JWT。

## 2. 本轮完成内容
- 完成后端技术基线确认
- 完成 `users` 表初始化脚本
- 完成 `User` 实体
- 完成 `UserMapper`
- 完成注册 / 登录请求 DTO
- 完成统一返回结构 `Result`
- 完成业务异常 `BusinessException`
- 完成全局异常处理 `GlobalExceptionHandler`
- 完成注册服务接口与实现
- 完成 `POST /api/auth/register`
- 完成用户名唯一校验
- 完成邮箱唯一校验
- 完成密码 BCrypt 加密存储

## 3. 关键技术点
- Spring Boot
- MyBatis-Plus
- Hibernate Validator
- BCryptPasswordEncoder
- PostgreSQL
- 全局异常处理
