# v4.4 - 上线前稳定性与安全复查

## 目标

在正式 Docker 生产编排前，复查生产配置、安全边界、CORS、日志、文件访问、上传限制、Redis 和 MinIO，补齐影响上线的明显缺口。

## 完成内容

- 检查生产 `.env` 必填项边界，确认真实密钥只能放在服务器 `.env`。
- 检查 JWT、数据库密码、AI / Embedding Key、MinIO Secret、Redis 密码的生产配置要求。
- 将 CORS 从硬编码本地开发地址改为 `APP_CORS_ALLOWED_ORIGIN_PATTERNS` 配置化。
- 新增 `SecurityCorsProperties`，并在 `SecurityConfig` 中通过 `@EnableConfigurationProperties` 显式加载，兼容 WebMvcTest 切片测试。
- 复查文件上传、文件访问、MinIO bucket、Redis 缓存、日志脱敏和异常返回边界。
- 新增 `docs/security-checklist.md`，记录上线前安全检查项和当前结论。
- 将 v4.4 状态和复查结果沉淀到 Phase 5 阶段记录。
