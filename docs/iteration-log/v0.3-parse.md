# v0.3 文本提取与结构化解析

## 1. 本轮目标
按小闭环逐步推进简历解析能力，完成从已上传简历读取文件、提取文本、基础结构化解析、保存解析结果、前端触发和展示的主链路。

本轮只负责文本提取、解析结果保存和基础结构化解析，不进入 AI 分析、岗位匹配和优化建议。

## 3. 关键技术点
- Apache PDFBox
- Apache POI
- objectKey 回读上传文件
- MyBatis-Plus BaseMapper
- PostgreSQL 外键、唯一约束和 CHECK 约束
- 解析结果覆盖更新策略
- 规则解析与正则提取
- Jackson ObjectMapper 序列化结构化结果
- Spring Security 当前用户隔离
- Vue 3 + Element Plus 表格操作和结果展示
- Axios API 封装

## 4. 遇到的问题
- 规则解析能提取稳定字段，但不同简历模板下教育、项目、实习等字段划分不稳定。
- 前端缺少删除闭环，后端删除简历后列表仍可能显示旧数据。
- 解析失败、未解析、重复解析和用户隔离都需要单独处理。

## 5. 解决方式
- 增加解析失败记录策略，保存 `FAILED` 和 `error_message`。
- 增加重复解析覆盖旧结果策略，保持一份简历只有一条最新解析结果。
- 补齐 `DELETE /api/resumes/{id}`，删除解析结果、简历记录和本地文件，前端删除后刷新列表并清空当前解析面板。
- 前端展示未解析、解析失败、加载中和接口错误状态。

## 6. 当前不足
- 基础结构化解析仍是规则版本，字段划分受简历模板影响。
- 图片型简历、扫描型简历和复杂 OCR 暂不支持。
- 还没有自动化集成测试覆盖上传、解析、查询和用户隔离完整链路。
- 完整 `./mvnw test` 仍受既有 Mockito / ByteBuddy 测试环境问题影响。
- DOC/DOCX 复杂版式下文本顺序仍可能不稳定。
- AI 分析尚未实现，已进入 v0.4 准备阶段。
