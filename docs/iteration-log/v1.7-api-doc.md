# v1.7 - OpenAPI / Knife4j 接口文档

## 目标

为 Phase 1 MVP 的核心后端接口补充可查看、可调试、可交付的接口文档，并明确 JWT 认证方式。

## 完成内容

- 引入 `springdoc-openapi-starter-webmvc-ui`，提供 OpenAPI JSON 和 Swagger UI。
- 新增 `OpenApiConfig`，配置接口文档标题、版本、描述和 JWT Bearer 认证方案。
- 在安全配置中放行接口文档路径：
  - `/v3/api-docs/**`
  - `/v3/api-docs.yaml`
  - `/swagger-ui/**`
  - `/swagger-ui.html`
- 为 Auth、User、Resume、Analysis、Job、Job Match、History 等核心 Controller 补充接口分组和接口说明。
- 为注册、登录、简历、AI 分析、岗位、岗位匹配、历史记录等核心 DTO / VO 补充字段说明。
- 为统一响应结构 `Result<T>` 补充字段说明。
- 更新 README，补充 Swagger UI、OpenAPI JSON 和 JWT 调试方式。
- 扩展 `Phase1ApiIntegrationTest`，验证 `/v3/api-docs` 可以匿名访问，并覆盖 OpenAPI JWT 配置。

## 接口文档访问方式

后端启动后访问：

```text
Swagger UI: http://localhost:8080/swagger-ui/index.html
OpenAPI JSON: http://localhost:8080/v3/api-docs
```

需要登录的接口使用 `bearerAuth`。调试时先调用 `/api/auth/login` 获取 `token`，再在 Swagger UI 的 `Authorize` 中填写 token。

## 技术取舍

本轮采用 Spring Boot 3 可直接使用的 `springdoc-openapi-starter-webmvc-ui` 完成 OpenAPI 3 和 Swagger UI 接入。v1.7 的核心目标是让接口文档可访问、可调试、可交付，不额外引入更复杂的文档增强能力。
