# v4.7.1 - SiliconFlow Embedding 接入修正

## 目标

将现有 OpenAI-compatible Embedding 客户端整理为可直接调用 SiliconFlow Embeddings API，同时保持业务模块、向量表结构和匹配主流程不变。

## 完成内容

- 将默认 Embedding base-url 调整为 `https://api.siliconflow.cn/v1`。
- 将默认 Embedding 模型调整为 `Qwen/Qwen3-Embedding-0.6B`。
- 将默认向量维度保持为 `1024`，并在请求体中按配置携带 `dimensions`。
- 将 Embedding 超时时间配置统一为 `timeout-seconds`，默认 `120` 秒。
- 增强 OpenAI-compatible Embedding 客户端的配置校验、响应解析、维度校验和 HTTP 错误提示。
- 补充单元测试覆盖请求体、响应解析、维度校验、空 API Key 和 HTTP 401 / 429 / 5xx 映射。
- 更新 `.env.example`、`README.md` 和 `docs/codex-context.md` 中的 SiliconFlow 配置说明。

## 当前不足

- 真实 SiliconFlow API 调用依赖本地或生产环境提供 `EMBEDDING_API_KEY`，本次未提交真实密钥。
- 本次只验证客户端构造和错误处理，不调用真实外部 API。
