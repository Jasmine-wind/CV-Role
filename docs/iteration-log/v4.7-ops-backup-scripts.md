# v4.7 - 数据备份、日志与运维脚本

## 目标

补齐单机生产 Compose 部署下的基础运维能力，包括备份、恢复、日志查看和服务重启。

## 完成内容

- 新增 `scripts/ops/backup-postgres.sh`，用于通过生产 Compose 备份 PostgreSQL。
- 新增 `scripts/ops/restore-postgres.sh`，用于从 SQL 备份恢复 PostgreSQL。
- 新增 `scripts/ops/backup-minio.sh`，用于备份 MinIO `/data` 对象数据。
- 新增 `scripts/ops/backup-uploads.sh`，用于备份 local uploads 兼容目录。
- 新增 `scripts/ops/show-logs.sh`，用于查看生产 Compose 日志。
- 新增 `scripts/ops/restart-services.sh`，用于重启生产 Compose 服务。
- 新增 `docs/ops-guide.md`，说明脚本调用方式。
- 更新 `docs/ops.md`，将 Redis、MinIO、日志和备份说明调整到当前实现状态。
- 更新 `docs/phase-5-productization-deployment-v4.md` 中 v4.7 的状态和验证结果。
