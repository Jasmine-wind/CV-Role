# v4.2 - Redis 正式接入与缓存增强

## 目标

将 Redis 从本地依赖预留升级为后端真实缓存能力，至少接入一个业务场景，并保证 Redis 不可用时不影响主业务流程。

## 完成内容

- 新增 `spring-boot-starter-data-redis`。
- 新增 `RedisCacheConfig`，显式配置 `StringRedisTemplate`。
- 新增 `RedisCacheProperties`，读取 `app.cache.redis.*`。
- 新增 `RedisJsonCacheService`，用 JSON 字符串读写 Redis 缓存。
- 在 `ResumeDisplayModelServiceImpl` 中接入 Redis，作为 AI 简历展示模型缓存。
- AI 展示模型缓存 key 包含 `resumeId`、结构化输入 hash、展示 Prompt 版本、模型名和展示适配器版本。
- 缓存写入同时保留本地内存缓存，Redis 读取或写入失败时只记录 warning，不影响用户主流程。
- `application.yaml` 补充 `spring.data.redis.*` 和 `app.cache.redis.*`。
- `application-test.yaml` 默认关闭 Redis cache。
- `.env.example` 补充 Redis 连接、超时、TTL 和 key prefix 配置。
- 确认当前 `docker-compose.yml` 已包含 Redis 服务；生产 Compose 留到 v4.5 统一编排。

## 当前不足

- 尚未用真实 Redis 容器做浏览器端到端缓存命中验收。
- 生产 `docker-compose.prod.yml` 尚未创建，Redis 生产编排留到 v4.5。
- 当前只接入 AI 展示模型缓存，AI 匹配结果、岗位解析结果和 Embedding 缓存留作后续可选增强。

## 结果

v4.2 已完成 Redis 正式接入。Redis 当前用于 AI 简历展示模型缓存，缓存具备 key 规范、TTL、降级策略和测试环境关闭开关，不保存唯一核心业务结果。
