# v2.7 - AI 输出评估流程

## 目标

建立基础 AI 输出质量评估流程，避免 Prompt 修改后质量不可控。

v2.7 只负责评估集、评估维度、输出记录、人工评分和 Prompt 修改规则，不新增 AI 业务功能，不做模型微调、自动打分系统、大规模测试集或复杂 A/B 测试平台。

## 完成内容

- 创建 `docs/evaluation/` 评估集目录。
- 创建样例简历目录 `docs/evaluation/resumes/`。
- 创建样例岗位描述目录 `docs/evaluation/job-descriptions/`。
- 创建 AI 输出记录目录 `docs/evaluation/outputs/`。
- 创建简历诊断、目标岗位解析、匹配分析、岗位优化建议和局部改写的输出子目录。
- 创建人工评估报告目录 `docs/evaluation/reports/`。
- 新增 `docs/evaluation/README.md`，说明目录用途、命名规则、可提交内容和禁止提交内容。
- 新增 `docs/evaluation/evaluation-notes.md`，说明评估目标、评估维度、评分建议和隐私边界。
- 明确样例文件、AI 输出文件和评估报告文件的命名规则。
- 明确评估集不得包含真实个人隐私、API Key、Token、完整请求头或完整系统 Prompt。
- 新增 `docs/evaluation/resumes/resume-sample-001.md`，用于 Java 后端实习方向评估。
- 新增 `docs/evaluation/resumes/resume-sample-002.md`，用于 AI 应用开发方向评估。
- 新增 `docs/evaluation/resumes/resume-sample-003.md`，用于数据分析或算法实习方向评估。
- 三份样例简历均包含候选人背景、目标方向、教育经历、技能、项目经历、可选实习或奖项、预期优势和预期问题。
- 三份样例简历均为虚构内容，不包含真实姓名、手机号、邮箱、住址、身份证号、学号或真实学校。
- 新增 `docs/evaluation/job-descriptions/jd-sample-001.md`，用于 Java 后端实习岗位评估。
- 新增 `docs/evaluation/job-descriptions/jd-sample-002.md`，用于 AI 应用开发实习岗位评估。
- 新增 `docs/evaluation/job-descriptions/jd-sample-003.md`，用于数据分析或算法实习岗位评估。
- 三份样例岗位描述均包含岗位名称、岗位方向、职责、必备技能、加分技能、经验信号、预期关键词和匹配关注点。
- 三份样例岗位描述均为虚构内容，不对应真实公司，不包含真实招聘方内部信息。
- 在 `docs/evaluation/evaluation-notes.md` 中补充 `relevance`、`factualConsistency`、`specificity`、`usefulness`、`structureStability`、`explainability`、`safety` 七个评估维度。
- 为每个评估维度定义 1 到 5 分评分标准。
- 明确 AI 输出评估的扣分规则和严重问题判定标准。
- 新增人工评估记录模板，便于后续逐条记录 AI 输出评分。
- 新增 `docs/evaluation/reports/evaluation-report-v1.md`，作为阶段性人工评估汇总报告模板。
- 选择 `resume-sample-001` 和 `jd-sample-001` 作为第一轮 Prompt 输出记录样例。
- 新增 `docs/evaluation/outputs/job-description-parse/jd-sample-001_prompt-job-description-parse-v1.md`，记录目标岗位解析输出。
- 新增 `docs/evaluation/outputs/resume-analysis/resume-sample-001_prompt-resume-analysis-v1.md`，记录简历 AI 分析输出。
- 新增 `docs/evaluation/outputs/ai-job-match/resume-sample-001_jd-sample-001_prompt-ai-job-match-v1.md`，记录匹配分析输出。
- 新增 `docs/evaluation/outputs/ai-suggestions/resume-sample-001_jd-sample-001_prompt-resume-suggestion-v1.md`，记录优化建议输出。
- 新增 `docs/evaluation/outputs/rewrite-suggestions/resume-sample-001_jd-sample-001_prompt-rewrite-suggestion-v1_parse-failed.md`，记录局部改写解析失败样例。
- 每份输出记录均包含样例编号、Prompt 名称、Prompt 版本、模型名称、生成时间、解析状态、原始输出、结构化输出和备注。
- 更新 `docs/evaluation/reports/evaluation-report-v1.md`，完成 5 条输出记录的人工评分。
- 在评估报告中记录各能力的 `relevance`、`factualConsistency`、`specificity`、`usefulness`、`structureStability`、`explainability` 和 `safety` 分数。
- 汇总 `FORMAT_ERROR`、`HALLUCINATION`、`VAGUE_SUGGESTION`、`MISSING_EVIDENCE`、`OVER_OPTIMIZATION`、`UNSAFE_CONTENT` 和 `LOW_RELEVANCE` 问题分类。
- 标记 `rewrite_suggestion_v1` 输出格式错误为本轮严重问题。
- 形成 Prompt 修改计划，优先处理局部改写 JSON 结构稳定性，其次优化匹配分析对必备技能和加分技能的区分。
- 更新 `docs/evaluation/evaluation-notes.md`，补充问题分类和 Prompt 修改规则。
- 完成 v2.7 任务清单压缩，将 `docs/tasks/phase-3-task-list.md` 中 v2.7 详细任务收口为总结和小任务完成情况表。

## 验证结果

v2.7.1 至 v2.7.7 均为文档、评估样例、输出记录、人工评分和阶段收口任务，未涉及代码编译或接口测试。

## 当前不足

- 当前已完成评估集目录设计、样例简历准备、样例岗位描述准备、评分维度设计、报告模板准备、第一轮输出记录、人工评分和 Prompt 修改规则整理。
- 当前输出记录主要用于跑通评估流程；如后续替换为真实联调输出，需要重新评分。
- 当前尚未进入 Embedding、pgvector 或 RAG 实现；这些内容留到 v2.8。

## 结果

v2.7 已完成 AI 输出评估流程闭环：评估目录、样例简历、样例岗位描述、评分规则、输出记录、人工评估报告和 Prompt 修改规则均已落地。评估结论显示优化建议整体表现最好，局部改写需要优先加强 JSON 输出稳定性。

下一步进入 v2.8，开始 Embedding / pgvector / RAG 初步增强。
