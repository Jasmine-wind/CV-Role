# v2.5 - AI 局部改写建议

## 目标

基于用户选择的简历片段、岗位描述、AI 匹配结果和 AI 优化建议，生成局部表达优化建议，并允许用户采纳或拒绝。

v2.5 只做局部改写建议，不自动修改原始简历文件，不生成完整定制版简历，不做 RAG、pgvector 或多轮对话。

## 完成内容

- 新增 `ai_rewrite_suggestions` 表迁移脚本。
- 新增 `AiRewriteSuggestion` 实体和 `AiRewriteSuggestionMapper`。
- 建立局部改写建议与简历、岗位描述、AI 匹配结果、AI 优化建议的可选关联关系。
- 明确 `rewrite_type`、`target_section`、`original_text`、`rewritten_text`、`rewrite_reason`、`caution`、`accept_status`、`rewrite_status`、`model_name`、`prompt_version`、`error_message` 等字段。
- 新增 `rewrite_suggestion_v1` Prompt，输入为原文片段、改写对象类型、目标简历部分，以及可选岗位描述结构化结果、AI 匹配结果和 AI 优化建议。
- Prompt 明确要求只优化当前片段，不生成完整简历，不编造经历、技术栈、证书、奖项或虚假量化指标。
- 新增局部改写 Prompt 构建服务。
- 新增局部改写输出解析服务，校验 `rewrittenText`、`rewriteReason`、`caution`、`needUserSupplement` 和 `supplementQuestions`。
- 新增局部改写业务服务，完成用户归属校验、上下文查询、AI 调用、结果保存和失败状态记录。
- 新增 `POST /api/resumes/{resumeId}/rewrite-suggestions`，用于生成局部改写建议。
- 新增 `GET /api/resumes/{resumeId}/rewrite-suggestions`，用于查询某份简历的局部改写建议，并支持按改写类型和采纳状态筛选。
- 新增 `PATCH /api/rewrite-suggestions/{rewriteId}/accept-status`，用于记录用户采纳或拒绝改写建议。
- 后端校验用户只能生成、查看和更新自己的局部改写建议。
- 新增前端局部改写 API 和类型定义。
- 在 AI 匹配页面增加局部改写弹窗。
- 前端支持选择改写对象类型、填写目标简历部分、输入原文片段，并自动关联当前岗位描述、AI 匹配结果和 AI 优化建议。
- 前端展示原文与改写建议对比、改写理由、注意事项、生成状态、采纳状态和历史改写建议列表。
- 前端增加“采纳”和“拒绝”按钮。
- 前端增加“AI 改写建议需用户确认”的提示。
- 修复采纳/拒绝接口因 `PATCH` 未加入 CORS allowed methods 导致浏览器预检失败的问题。
- 将 `/api/rewrite-suggestions/**` 纳入 Spring Security 鉴权路径。

## 验证结果

已执行局部改写 Prompt、输出解析和业务服务测试：

```bash
cd backend
./mvnw -Dtest=AiRewriteSuggestionPromptServiceImplTest,AiRewriteSuggestionOutputParserImplTest,AiRewriteSuggestionServiceImplTest test
```

已执行局部改写接口和 API 集成测试：

```bash
cd backend
./mvnw -Dtest=AiRewriteSuggestionServiceImplTest,Phase1ApiIntegrationTest test
```

已执行采纳/拒绝接口修复后的 API 集成测试：

```bash
cd backend
./mvnw -Dtest=Phase1ApiIntegrationTest test
```

已执行前端构建：

```bash
cd web
npm run build
```

已完成本地手动联调：

- 前端可以基于当前简历片段提交局部改写请求。
- 局部改写建议可以成功保存并查询。
- 前端可以展示原文、改写建议、改写理由和注意事项。
- 前端可以展示历史改写建议列表并切换查看。
- 前端可以采纳或拒绝局部改写建议。
- 采纳或拒绝只更新 `accept_status`，不会修改原始简历文件或解析结果。
- 原文为空时返回明确错误。
- AI 返回格式错误时保存失败状态和错误信息，不保存脏改写正文。
- 用户不能生成、查看或更新他人的局部改写建议。
- 日志只记录用户 ID、简历 ID、关联结果 ID、模型和脱敏错误原因，不输出完整 Prompt、简历原文、API Key 或 Token。

## 当前不足

- 局部改写仍依赖模型稳定返回 JSON，复杂输入下仍可能出现格式异常。
- 当前事实一致性主要依赖 Prompt 约束、输出结构校验和用户确认，尚未做自动事实比对。
- 当前采纳状态只记录用户决策，不自动生成最终简历版本。
- 当前未实现简历内容替换、PDF/DOCX 导出或完整定制版简历生成。
- 当前局部改写结果尚未纳入统一 AI 历史视图，后续由 v2.6 处理。

## 结果

v2.5 已完成 AI 局部改写建议闭环。当前系统可以基于用户选择的简历片段生成结构化改写建议，支持保存、查询、前端对比展示，并记录用户采纳或拒绝状态，同时保持不自动修改原始简历和不编造经历的边界。

下一步进入 v2.6，统一管理 AI 分析、岗位描述解析、AI 匹配、优化建议和局部改写等 AI 结果，支持历史回看。
