## 关键改动

- `SecurityConfig` 默认策略由 `anyRequest().permitAll()` 改为 `anyRequest().authenticated()`，只保留注册、登录、Swagger 和预置岗位库公开访问。
- 简历、目标岗位、AI 结果、报告、历史、异步任务和 Embedding 均按当前用户归属查询或二次校验。
- 上传文件新增真实内容签名校验，PDF 识别 `%PDF-`，DOC 识别 OLE CFB，DOCX 校验 zip 内 Word 必要条目。
- 本地存储路径解析拒绝反斜杠、空字节和路径穿越，VO 不返回服务器真实路径或内部 `objectKey`。
- `.env.example` 和 `docker-compose.yml` 中的数据库、MinIO 示例密码改为明显本地占位值，README 改为引用 `.env.example` 并提示替换私有值。
- `LogSanitizer` 增加手机号、邮箱、本地绝对路径和 Windows 绝对路径脱敏；业务异常返回前也经过脱敏。
- 异步任务失败、AI / Embedding 调用失败、结构化解析 fallback、展示模型 fallback 等日志不再默认输出完整异常栈或未脱敏 message。
- AI / Embedding 边界已记录：不会发送 API Key、JWT Token、Authorization header、完整请求头、服务器路径、数据库密码、MinIO Secret 或内部文件路径。
