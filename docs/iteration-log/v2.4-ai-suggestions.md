# v2.4 - AI 简历优化建议增强

## 目标

基于 v2.3 的 AI 岗位匹配结果，生成具体、有依据、可保存、可查询、可展示的简历优化建议。

v2.4 只做 AI 简历优化建议，不生成完整简历，不做局部改写、RAG、pgvector 或多轮对话。

## 完成内容

- 新增 `ai_resume_suggestions` 表迁移脚本。
- 新增 `AiResumeSuggestion` 实体和 `AiResumeSuggestionMapper`。
- 建立优化建议与简历、岗位描述、AI 匹配结果的关联关系。
- 对同一 `ai_job_match_result_id` 设置唯一约束，重复生成时覆盖旧建议。
- 新增 `resume_suggestion_v1` Prompt，输入为简历结构化解析结果、岗位描述结构化解析结果和 AI 匹配结果。
- Prompt 要求只基于输入内容提出建议，不编造用户不存在的经历、技能、证书、奖项或量化指标。
- 新增优化建议 Prompt 构建、输出解析和业务编排服务。
- 输出解析校验建议类型、优先级、问题、建议内容和依据，格式异常时不保存成功状态结果。
- AI 建议生成成功时保存 `SUCCESS`、结构化建议、模型名称和 Prompt 版本。
- AI 调用失败或输出解析失败时保存 `FAILED` 和错误信息，并清空建议内容。
- 新增 `POST /api/resumes/{resumeId}/ai-suggestions`，触发当前用户简历的优化建议生成。
- 新增 `GET /api/resumes/{resumeId}/ai-suggestions`，支持列表查询，也支持按 `jobDescriptionId` 或 `aiJobMatchResultId` 查询指定结果。
- 后端校验用户只能基于自己的简历、岗位描述和 AI 匹配结果生成或查看建议。
- 新增前端优化建议 API 和类型定义。
- 在 AI 匹配页面增加“生成优化建议”和“刷新建议”入口。
- 前端展示建议状态、建议数量、建议类型、优先级、目标部分、问题、建议、依据、注意事项、模型名称和生成时间。
- 前端按高优先级、技能缺口、经历表达、优势与综合建议分组展示。
- 前端增加“AI 建议需用户确认，不应直接伪造经历”的提示。

## 验证结果

已执行优化建议服务、Prompt 和输出解析相关后端测试：

```bash
cd backend
./mvnw -Dtest=AiResumeSuggestionPromptServiceImplTest,AiResumeSuggestionOutputParserImplTest,AiResumeSuggestionServiceImplTest test
```

已执行优化建议查询接口和 API 集成测试：

```bash
cd backend
./mvnw -Dtest=AiResumeSuggestionServiceImplTest,Phase1ApiIntegrationTest test
```

已执行前端构建：

```bash
cd web
npm run build
```

已完成本地手动联调：

- 前端可以基于成功 AI 匹配结果触发优化建议生成。
- 优化建议可以成功保存并查询。
- 前端可以展示建议类型、优先级、目标部分、问题、建议、依据和注意事项。
- 重复生成会覆盖同一 AI 匹配结果对应的旧建议。
- 未完成 AI 匹配时不能生成优化建议，并返回明确提示。
- AI 返回格式错误时保存失败状态和错误信息，不保存脏建议。
- 日志只记录用户 ID、简历 ID、岗位描述 ID、匹配结果 ID、模型和脱敏错误原因，不输出完整 Prompt、简历原文、API Key 或 Token。

## 当前不足

- 优化建议仍依赖模型稳定返回 JSON，复杂输入下仍可能出现格式异常。
- 当前只保存结构化建议和错误信息，不保存原始 AI 输出。
- 建议依据主要来自模型对输入内容的总结，尚未做更细粒度证据定位。
- 当前前端在没有某类建议时显示空分组，后续可根据体验决定是否只展示有内容的分组。
- 当前只生成建议，不生成局部改写文本；局部改写由 v2.5 处理。

## 结果

v2.4 已完成 AI 简历优化建议闭环。当前系统可以基于成功的 AI 岗位匹配结果生成结构化、可保存、可查询、可展示的简历优化建议，并保留不编造经历和不直接生成完整简历的边界。

下一步进入 v2.5，基于已有优化建议继续实现局部改写建议。
