# v4.6 - Docker Compose 服务器部署、域名与 HTTPS

## 目标

把生产 Compose、域名解析、Nginx 反向代理和 HTTPS 收口成可执行的服务器部署流程。

## 完成内容

- `docker-compose.prod.yml` 增加 `443` 暴露、`certbot` profile、`certbot_www` 和 `letsencrypt` 持久化卷。
- `deploy/nginx/conf.d/ai-resume.conf` 增加 `/.well-known/acme-challenge/` 路径，支持 Certbot 的 HTTP-01 验证。
- 新增 `deploy/nginx/conf.d/ai-resume-https.conf`，作为正式 HTTPS 模板，包含 HTTP 到 HTTPS 跳转和 443 SSL 配置。
- `.env.production.example` 增加 `DEPLOY_DOMAIN` 和 `CERTBOT_EMAIL`。
- `docs/deployment.md` 补充生产 Compose、证书申请和 HTTPS 切换步骤。
- 将 v4.6 的状态、任务和验证结果沉淀到 Phase 5 阶段记录。

## 当前不足

- 真实服务器上的域名解析、证书申请和 HTTPS 切换还需要实际部署环境完成。
- 证书自动续期与故障恢复进入 v4.7。
