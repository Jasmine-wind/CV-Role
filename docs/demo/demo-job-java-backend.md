# 虚构 Java 后端岗位样例

说明：本样例仅用于本地演示，不代表真实招聘岗位。

## 岗位名称

Java 后端开发工程师

## 岗位职责

- 参与业务系统后端服务设计、开发、测试和上线。
- 负责 RESTful API 开发、接口联调和问题排查。
- 参与订单、用户、权限、消息通知等业务模块建设。
- 配合前端、测试和产品完成需求交付。
- 参与系统性能优化和稳定性改进。

## 任职要求

- 熟悉 Java 基础，理解集合、多线程和常见设计模式。
- 熟悉 Spring Boot、Spring MVC、MyBatis 等 Java Web 开发框架。
- 熟悉 MySQL，了解索引、事务和基础 SQL 优化。
- 熟悉 Redis 缓存使用场景。
- 了解 RabbitMQ 或其他消息队列。
- 熟悉 Git、Maven、Linux 基础命令。
- 有订单、工单、权限、消息通知等业务系统经验优先。
- 了解 Docker 或容器化部署者优先。

## 加分项

- 有接口性能优化经验。
- 有线上问题排查经验。
- 能清晰描述项目职责和技术取舍。
