# 项目上下文与当前状态

更新基线：本次 V2 前置仓库整理。本文只记录**当前事实、已确认决策和已知差距**；产品目标见 [PRD.md](PRD.md)，实现顺序见 [PLAN.md](PLAN.md)。

## 1. 当前定位

仓库当前实现是一个可运行、可部署的 V1：围绕简历和目标 JD 提供解析、诊断、匹配、建议、局部改写、报告与历史回看。它已验证主要技术能力，但用户仍需理解和手动串联多个 AI 步骤。

V2 的产品判断已经冻结：产品不是 AI 功能展示平台、ATS 分数器或完整简历自由生成器；目标是让用户只提供真实简历、目标 JD 和偏好，系统在事实边界内完成分析、修改和 PDF 交付。

## 3. 当前页面与主流程

当前一级入口实际包括：工作台、我的简历、岗位库、目标岗位、匹配与优化、AI 历史。工作台使用进度 Stepper、状态卡和推荐动作引导用户。

当前流程：

```text
登录
→ 上传简历
→ 手动解析 / 手动诊断
→ 新建目标岗位 / 手动解析
→ 选择简历和岗位生成匹配
→ 生成建议
→ 局部改写与采纳
→ 报告 / AI 历史
```

这些页面和接口仍服务当前实现。本次整理没有删除被运行时引用的业务代码，也没有改变业务行为。

## 4. 与 V2 的主要差距

当前尚未具备或尚未收敛：

- 上传后自动解析、粘贴 JD 后一键分析的最短链路。
- `ResumeVersion`、岗位定向版本、可复现的 `OptimizationTask` 快照。
- 岗位要求 ↔ 真实经历 ↔ 当前表达的显式证据映射。
- “可通过表达修改解决”与“真实经历未覆盖”的稳定领域模型。
- 可直接编辑的 Workspace、自动保存、Undo / Redo 和恢复点。
- Diff、Apply / Reject 与事实校验组成的完整可控修改体验。
- Structured Resume JSON 驱动的 Typst Preview / PDF Export。
- 每用户 BYOK、Credential 加密、AI Gateway 与自定义 Base URL SSRF 防护。
- 用户数据导出 / 全量删除和长期多 JD 方向洞察。

当前仍存在而 V2 明确不作为最终产品入口的能力：岗位库、技术分类式 AI 历史、Dashboard 指标 / Stepper、多个手动生成按钮。它们只能在后续替代链路验收后迁移或删除，不能仅按 PRD 直接删代码。

## 5. 已确认并保留的历史决策

- 模块化单体和前后端分离足以支撑 V2；不为重构引入微服务、消息队列或 Kubernetes。
- 用户粘贴的真实 JD 是主输入；自动采集和招聘网站爬虫不进入范围。
- AI 只能优化表达和排序，不能新增未验证技术、经历、日期、公司、成果或数字。
- 报告与历史查询不触发新的 AI 生成。
- 外部 AI / Embedding、Redis 和文件系统通过后端适配；业务层不直接处理密钥或供应商 HTTP 细节。
- Redis 失败应尽量降级，不影响数据库中的核心业务事实。
- 文件存储由接口抽象，读取必须经过资源归属检查。
- 数据库迁移以 Flyway 为唯一机制；早期手动 `db/init` 脚本已失效并删除。
- 异步任务使用真实阶段 / 状态，不伪造百分比；错误信息必须脱敏。

## 6. 当前质量与风险

- 后端测试数量较多，但完整测试依赖 PostgreSQL；本地环境配置错误会导致 context test 失败。
- CI 使用 PostgreSQL 服务执行 `./mvnw test`，前端执行 `npm ci` 与 `npm run build`。
- 生产 Nginx Compose 默认加载 HTTP 配置；HTTPS 模板切换和证书操作仍需按 `OPERATIONS.md` 人工执行。
- 线上地址、域名、证书和服务器状态属于运行环境事实，不能仅由仓库测试证明。

## 7. 本次基线验证

- 前端 `npm run build`：通过。
- 后端在本机 Java 25 下以 `./mvnw -Dmaven.compiler.proc=full test` 运行：309 个测试通过，2 个真实外部服务 smoke test 跳过。
- 后端在 Java 25 下直接执行 `./mvnw test` 会因新版 javac 默认不扫描 classpath annotation processor 而缺失 Lombok 生成代码；仓库要求 Java 21，CI 也使用 Java 21，本次不为本地 Java 25 修改业务构建配置。
- 本地与生产 Compose 模板 `config` 渲染：通过。
- Shell 运维脚本 `bash -n`：通过。
- Markdown 本地链接：无 broken link。
