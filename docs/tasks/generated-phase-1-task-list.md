# Phase 1 Task List

## 0. 文件用途

本文件用于拆解 Phase 1 的具体开发任务。

`docs/phase-1-mvp.md` 负责说明 Phase 1 要做什么。  
本文件负责说明每个版本下面具体怎么拆小任务。

使用原则：

1. 每次只做一个小任务。
2. 每个小任务都要有目标、任务、验收标准。
3. 完成一个小任务后，更新 `docs/codex-context.md`。
4. 完成一个 v0.x 版本后，更新对应迭代日志。
5. 不允许跳过当前任务直接实现后续版本功能。

- 已运行后端 `./mvnw -DskipTests package`。

# v0.3 - 文本提取与结构化解析

状态：当前版本

## v0.3 目标

从已上传简历中提取文本，并生成基础结构化解析结果。

v0.3 只负责文本提取、解析结果保存和基础结构化解析，不进入 AI 分析、岗位匹配和优化建议。

v0.3 完成后应满足：

- 系统可以从已上传的 PDF、DOC、DOCX 简历中提取文本。
- 提取结果可以保存并查询。
- 系统可以生成基础结构化字段。
- 用户只能触发和查看自己的简历解析结果。
- 前端可以展示文本提取结果和基础结构化解析结果。

---
