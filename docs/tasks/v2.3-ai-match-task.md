# v2.3 - 简历与岗位 AI 匹配分析

状态：当前版本

## v2.3 目标

基于简历解析结果和岗位描述解析结果，生成更结构化、更可解释的 AI 匹配反馈。

v2.3 只负责“简历 + 岗位描述”的 AI 匹配分析，不负责生成完整优化建议，不负责局部改写，不负责 RAG、pgvector 和多轮对话。

v2.3 完成后应满足：

- 已解析简历可以与已解析岗位描述进行 AI 匹配。
- 未解析简历不能直接进行 AI 匹配。
- 未解析岗位描述不能直接进行 AI 匹配。
- AI 匹配结果可以结构化保存。
- AI 匹配结果包含总体匹配分数、强匹配项、弱匹配项、缺失技能、表达较弱经历、匹配依据和风险提示。
- 匹配结论必须能够说明依据。
- AI 不得编造用户不存在的经历、技能、项目、证书或量化指标。
- 用户只能匹配和查看自己的简历与岗位描述。
- 前端可以展示 AI 匹配反馈。
- 本轮结果记录到 `docs/iteration-log/v2.3-ai-match.md`。

说明：

- v2.3 不生成最终简历优化方案。
- v2.3 不生成局部改写内容。
- v2.3 不做向量语义匹配。
- v2.3 不做 RAG。
- v2.3 不做 pgvector。
- v2.3 不做多轮对话。
- v2.3 的重点是让 AI 匹配结果结构化、可解释、可保存、可展示。

建议 AI 输出结构：

```json
{
  "overallScore": 82,
  "strongMatches": [
    {
      "item": "Java",
      "reason": "简历技能中出现 Java，岗位必备技能中包含 Java"
    }
  ],
  "weakMatches": [
    {
      "item": "Redis",
      "reason": "简历中只提到了解 Redis，但缺少项目实践描述"
    }
  ],
  "missingSkills": [
    {
      "item": "Docker",
      "reason": "岗位要求 Docker，但简历解析结果中未发现相关内容"
    }
  ],
  "weakExperienceDescriptions": [
    {
      "section": "项目经历",
      "issue": "项目描述有技术栈，但缺少个人职责和结果说明"
    }
  ],
  "evidence": [
    {
      "source": "resume",
      "content": "简历中提到 Spring Boot 项目开发"
    },
    {
      "source": "job",
      "content": "岗位要求熟悉 Spring Boot"
    }
  ],
  "riskNotes": [
    "部分技能只在技能列表中出现，缺少项目支撑"
  ]
}
```

输出字段说明：

| 字段 | 说明 |
|---|---|
| overallScore | 总体匹配分数，0 到 100 |
| strongMatches | 强匹配项 |
| weakMatches | 弱匹配项 |
| missingSkills | 缺失技能 |
| weakExperienceDescriptions | 表达较弱的经历描述 |
| evidence | 匹配依据 |
| riskNotes | 风险提示 |

验收标准：

- Prompt 明确要求不编造经历。
- Prompt 明确要求提供匹配依据。
