# jd-sample-001

## jobTitle

Java 后端开发实习生

## jobDirection

后端开发 / Java / Web 服务开发

## sourceNote

完全虚构岗位描述，仅用于 AI 输出评估。不对应真实公司，不包含真实招聘方内部信息。

## responsibilities

- 参与业务系统后端接口开发，完成用户、订单、内容或配置类模块的 CRUD 能力。
- 根据接口文档完成 RESTful API 开发、参数校验、异常处理和统一返回。
- 参与数据库表设计、SQL 编写和接口联调。
- 协助排查测试环境中的接口错误、数据异常和权限校验问题。
- 按团队规范提交代码，参与 Code Review 和基础单元测试编写。

## requiredSkills

- 熟悉 Java 基础语法、集合、异常处理和面向对象编程。
- 了解 Spring Boot 常见开发方式，能完成 Controller、Service、Mapper 分层开发。
- 熟悉 MySQL 或 PostgreSQL 基础 SQL，理解索引、事务和常见表关系。
- 了解 MyBatis 或 MyBatis-Plus 的基础使用。
- 了解 HTTP、RESTful API、JSON、JWT 等 Web 开发基础概念。
- 能使用 Git、Maven、Postman 等常见开发工具。

## bonusSkills

- 有 Redis 缓存、消息队列、Docker 或 Linux 使用经验。
- 有接口权限控制、用户归属校验或数据权限处理经验。
- 有完整课程项目、开源项目或实习项目经历。
- 能说明接口性能优化、慢 SQL 排查或错误日志定位经验。

## experienceSignals

- 做过 Spring Boot 后端项目。
- 描述过具体负责的接口、模块、表结构或权限逻辑。
- 能说明项目中的真实问题和解决方式。
- 有接口联调、测试、部署或日志排查经历。

## expectedKeywords

- Java
- Spring Boot
- MyBatis-Plus
- RESTful API
- SQL
- PostgreSQL
- MySQL

- Redis

- Postman

## matchingFocus

- 优先关注候选人是否有真实 Java 后端项目经历。
- 匹配分析应区分“了解”与“实际使用”，避免把基础接触夸大为深入掌握。
- 优化建议应鼓励补充接口数量、模块职责、数据表设计、权限校验和错误排查经历。
- 不应建议候选人编造高并发、消息队列或企业级架构经验。
