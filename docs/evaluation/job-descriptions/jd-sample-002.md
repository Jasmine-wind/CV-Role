# jd-sample-002

## jobTitle

AI 应用开发实习生

## jobDirection

AI 应用 / 大模型 API / Prompt / 知识库问答

## sourceNote

完全虚构岗位描述，仅用于 AI 输出评估。不对应真实公司，不包含真实招聘方内部信息。

## responsibilities

- 参与基于大模型 API 的应用原型开发，包括问答、摘要、信息抽取或内容生成场景。
- 根据业务需求设计和迭代 Prompt，记录不同版本输出效果。
- 协助整理评估样例，分析模型输出中的格式错误、事实不一致和回答空泛问题。
- 参与后端接口开发和前端联调，将 AI 输出展示到业务页面。
- 对接文档、知识片段或结构化数据，支持简单检索增强原型。

## requiredSkills

- 熟悉 Python 或 JavaScript，能够完成基础接口开发和脚本处理。
- 了解大模型 API 调用方式，理解 Prompt、上下文、Token 和结构化输出的基本概念。
- 了解 JSON 输出格式约束，能处理模型返回格式异常。
- 有 FastAPI、Flask、Node.js 或 Spring Boot 任一后端框架使用经验。
- 了解数据库基础，能存储和查询 AI 输出记录。
- 具备基本 Git、Linux 和接口调试能力。

## bonusSkills

- 有 RAG、Embedding、向量检索或知识库问答原型经验。
- 有 AI 输出人工评估、Prompt 版本对比或错误归因经验。
- 有 Vue、React 或其他前端联调经验。
- 能说明如何防止模型编造事实或泄露敏感信息。

## experienceSignals

- 做过可演示的大模型应用原型。
- 能描述 Prompt 如何迭代，以及为什么这样调整。
- 能说明模型输出格式异常时的处理方式。
- 有将 AI 结果保存、查询、展示到页面的经历。

## expectedKeywords

- Python
- 大模型 API
- Prompt
- JSON
- FastAPI
- RAG
- Embedding
- 知识库问答
- 结构化输出
- 人工评估
- Vue

## matchingFocus

- 优先关注候选人是否真正做过 AI 应用落地，而不仅是调用过聊天界面。
- 匹配分析应识别 Prompt 迭代、输出评估、结构化输出和接口联调经验。
- 优化建议应鼓励补充模型输出问题、评估方式、上下文来源和失败处理。
- 不应建议候选人编造模型微调、生产级 RAG 或大规模评测平台经验。
