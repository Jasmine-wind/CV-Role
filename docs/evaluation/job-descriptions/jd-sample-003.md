# jd-sample-003

## jobTitle

数据分析实习生

## jobDirection

数据分析 / Python / SQL / 业务指标

## sourceNote

完全虚构岗位描述，仅用于 AI 输出评估。不对应真实公司，不包含真实招聘方内部信息。

## responsibilities

- 协助业务团队完成数据提取、清洗、统计分析和可视化展示。
- 根据业务问题拆解指标，输出日报、周报或专题分析报告。
- 使用 SQL 查询订单、用户、行为或内容数据，定位数据波动原因。
- 使用 Python 对样例数据进行处理、建模或可视化。
- 参与分析结论复盘，将发现的问题转化为可执行建议。

## requiredSkills

- 熟悉 SQL，能够完成多表查询、聚合统计、条件筛选和基础窗口函数。
- 熟悉 Python 数据处理，掌握 Pandas、NumPy 或 Jupyter Notebook。
- 了解常见统计指标，如转化率、留存率、复购率、客单价和活跃用户。
- 能使用图表清晰表达分析结论。
- 具备基础统计学和机器学习概念，理解训练集、测试集、特征和评估指标。
- 具备良好的文字表达能力，能写清楚分析过程和结论。

## bonusSkills

- 有 Tableau、Power BI、Superset 或类似 BI 工具经验。
- 有 A/B 实验、漏斗分析、用户分群或异常波动分析经验。
- 有 scikit-learn 建模、特征工程或模型解释经验。
- 有业务报告、课程项目或实习项目沉淀。

## experienceSignals

- 项目中包含真实或模拟数据集的清洗和分析过程。
- 能说明指标口径、分析维度和结论依据。
- 能解释模型指标或业务指标的含义。
- 有将分析结果转化为业务建议的经历。

## matchingFocus

- 优先关注候选人的 SQL、Python 数据处理和指标分析能力。
- 匹配分析应区分数据分析经验和算法工程经验，避免把课程建模过度包装成生产算法经验。
- 优化建议应鼓励补充指标口径、样本规模、分析结论和业务动作。
- 不应建议候选人编造真实企业数据、商业结果或线上模型部署经验。
